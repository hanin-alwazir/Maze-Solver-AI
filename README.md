# Maze Solver AI (BFS vs A*) 🚀

An interactive artificial intelligence project designed to solve and analyze mazes using **Breadth-First Search (BFS)** and **A* Search** algorithms[cite: 3]. Developed as part of academic studies at Fahad Bin Sultan University[cite: 3].

## ✨ Features
- **Graphical User Interface (GUI):** Built with Python (`Tkinter`) allowing real-time visualization of the solving process[cite: 1, 3].
- **Algorithm Comparison:** Side-by-side competition between BFS and A* to evaluate performance metrics (visited nodes, path length, and execution time in milliseconds)[cite: 3].
- **Heuristic Optimization:** Utilizes the **Manhattan distance** heuristic in A* to guide the search efficiently toward the goal[cite: 3].
- **Customizable Environment:** Dynamic random maze generation with adjustable grid sizes, wall densities, display speeds, and sound effects[cite: 3].

## 🛠️ Tech Stack & Files
- **`maze_gui.py`**: Interactive desktop GUI application[cite: 1, 3].
- **`maze_ai.py`**: Core pathfinding algorithms (BFS and A*) implementation[cite: 2, 3].
- **`AI7.docx`**: Comprehensive project documentation and system architecture[cite: 3].
